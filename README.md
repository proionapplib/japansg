# japansg

Pages publiques de l'application iPhone **Japan SG** : confidentialité et support.
Elles sont servies par GitHub Pages et sont les adresses déclarées dans App Store Connect.

| Page | Adresse |
|---|---|
| Accueil | https://proionapplib.github.io/japansg/ |
| Confidentialité | https://proionapplib.github.io/japansg/confidentialite.html |
| Support | https://proionapplib.github.io/japansg/support.html |

Trois fichiers HTML statiques et une feuille de style, sans dépendance ni étape de
construction : modifier un fichier et pousser sur `main` suffit à mettre le site à jour.

Le code de l'application n'est pas ici : ce dépôt ne contient que ces pages.
